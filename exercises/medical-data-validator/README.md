# Medical Data Validator

A Python exercise from the freeCodeCamp Python curriculum focused on validating and processing structured medical records.

## Concepts Practiced

- Dictionaries
- Sets
- Lists
- String manipulation
- Regular expressions (`re`)
- Data validation
- Conditional logic
- Iteration

## Description

This exercise validates information stored in medical records and uses Python's built-in data structures and regular expressions to check whether specific values follow the required format.

It was completed as a progress exercise while working through the freeCodeCamp Python curriculum.
